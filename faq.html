Preguntas frecuentes

Preguntas sobre nuestras maquetas para imprimir

Aquí encontrarás respuestas a las preguntas más habituales sobre las maquetas escolares, los proyectos de ecosistemas, los archivos digitales, la impresión y el proceso de construcción.

La idea es que puedas saber rápidamente qué necesitas antes de empezar.

¿Estos productos son físicos o digitales?

Son productos digitales. Después de comprar recibirás acceso al archivo PDF para descargar e imprimir.

No se envía ningún producto físico por correo.

¿Qué recibo después de comprar?

Recibirás el archivo digital correspondiente al proyecto que hayas comprado. El PDF contiene las páginas necesarias para imprimir, recortar y construir la maqueta.

¿Cómo recibo la descarga?

Después de completar el pago, el sistema prepara automáticamente el enlace de descarga.

Si el pago se ha completado pero tienes algún problema con el archivo, puedes escribirme desde la página de contacto.

¿Qué necesito para construir una maqueta?

Para la mayoría de los proyectos solo necesitas una impresora, papel, tijeras y pegamento.

Muchos diseños están pensados para utilizarse dentro de una caja de zapatos o una caja de cartón similar. En algunos proyectos también puedes utilizar cartón adicional para reforzar el suelo o el fondo.

¿Necesito papel especial?

No necesariamente. Puedes imprimir los proyectos en papel normal de impresora.

Si quieres piezas un poco más resistentes, también puedes utilizar papel más grueso o pegar algunas piezas sobre cartulina o cartón fino.

¿Puedo imprimir el proyecto en casa?

Sí. Las maquetas están creadas para poder imprimirse con una impresora doméstica normal.

También puedes imprimirlas en una copistería o centro de impresión si lo prefieres.

¿En qué tamaño debo imprimir?

Lo mejor es imprimir las páginas al 100 % de su tamaño, sin seleccionar opciones como “ajustar a página” si estas modifican la escala original.

De esta manera, las distintas piezas mantienen las proporciones previstas para el proyecto.

¿Las maquetas sirven para proyectos escolares?

Sí. Muchas están diseñadas especialmente para proyectos escolares sobre ecosistemas, hábitats, animales y ciencias naturales.

Por ejemplo, puedes construir una maqueta de ecosistema terrestre, una maqueta de ecosistema acuático o una maqueta del ciclo del agua.

Los proyectos pueden utilizarse como base para una presentación escolar y después personalizarse con información, carteles o elementos adicionales.

¿Qué maquetas de ecosistemas puedo construir?

Actualmente hay varios hábitats y ecosistemas disponibles. Puedes crear un bosque, una selva tropical, un desierto, una sabana o un ecosistema marino.

Cada proyecto contiene fondos y piezas imprimibles para crear profundidad y convertir una caja sencilla en un pequeño escenario 3D.

¿Para qué edad son adecuadas?

Depende del niño y del proyecto. En general, las maquetas están pensadas para niños de primaria y mayores que ya pueden utilizar tijeras y pegamento con seguridad.

Los niños más pequeños pueden construirlas con ayuda de un adulto. De hecho, muchos proyectos son especialmente divertidos cuando se hacen juntos en familia.

¿Los niños tienen que construir exactamente el modelo del ejemplo?

No. Las fotografías muestran una forma posible de construir la maqueta, pero cada proyecto puede personalizarse.

Puedes cambiar la posición de los animales, añadir plantas, utilizar materiales adicionales, dibujar nuevos elementos o inventar una versión completamente propia.

¿Necesito una caja de zapatos exactamente del mismo tamaño?

No siempre. Las cajas de zapatos pueden variar bastante de tamaño.

Puedes adaptar las piezas al espacio disponible, recortar algunas partes o utilizar una caja de cartón de tamaño parecido. Lo importante es tener una base en la que puedas crear profundidad y colocar los distintos elementos.

¿Puedo imprimir el archivo más de una vez?

Sí, puedes volver a imprimir el archivo para tu propio uso personal, por ejemplo si una pieza se daña mientras estás construyendo.

¿Puedo utilizar una maqueta en mi clase?

Puedes utilizar el proyecto para realizar tu propia actividad o maqueta.

Si necesitas utilizar o distribuir copias para varios alumnos o para un grupo completo, ponte en contacto conmigo antes para consultar las opciones disponibles.

¿Puedo vender las maquetas terminadas o los archivos digitales?

Los archivos digitales no pueden copiarse, compartirse, revenderse ni redistribuirse.

Si tienes una idea de uso diferente y no estás seguro de si está permitido, escríbeme y lo vemos.

¿Qué pasa si tengo un problema con mi descarga?

Si el pago se ha completado y la descarga no funciona correctamente, ponte en contacto conmigo.

Incluye el correo utilizado para la compra y una breve explicación del problema para que pueda ayudarte más rápidamente.

¿Puedo pedir una maqueta sobre otro tema?

Siempre estoy trabajando en nuevos proyectos y probando nuevas ideas.

No puedo prometer que pueda crear cada petición, pero si hay un tema que te gustaría ver en Maquetas de Papel, puedes enviarme la sugerencia.

¿No encuentras tu respuesta?

No pasa nada. Si tienes una pregunta concreta sobre un proyecto, una compra o una descarga, puedes escribirme directamente.
